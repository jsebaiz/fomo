The Crew Sheet

Split every dinner into five jobs, and put a name on each one.

  • Reservations — books the room, confirms the headcount.
  • Guest list — locks the twelve, sends reminders.
  • Photos — shoots the table, keeps it disclosed.
  • Recap post — writes it up, tags fomo.
  • Receipts — handles the check, files it with the team.
